# 🛡️ Admin Guide — لوحة الأدمن

Only Telegram IDs listed in `ADMIN_IDS` (comma-separated) can see 🛡️ في القائمة أو استخدام الأوامر.
Anyone else gets «غير مصرّح» and the attempt is written to `admin_actions` (audit log).

---

## 1. Entry points

| Command | Result |
|---|---|
| `/admin` | لوحة الأدمن (buttons) |
| `/stats` | نفس صفحة الإحصائيات مباشرة |
| `/cap <usd>` | ضبط السقف اليومي العالمي لتكلفة API (مثال: `/cap 15`) |
| `/cap 0` | إلغاء السقف (بلا حد) |
| `/route <task> <model>` | تغيير موديل مهمة فورًا — المهام: `consultation coach vision workout_programme nutrition_plan boxing_programme progress_photo_analysis safety_screen day_recalculation summarization transcription` |
| `/route reset` | الرجوع للموديلات الافتراضية في الإعدادات |
| `/export` | تصدير CSV للمستخدمين (مرفق في نفس المحادثة) |

> التعديلات تُحفظ في جدول `app_settings` وتُطبَّق فورًا على كل العمليات (كاش TTL قصير).

## 2. Buttons

### 📊 الإحصائيات
مستخدمون (الكل/النشطون 7 أيام/المشتركون/المحظورون) · الإيراد بالنقاط (الكل/30 يوم) ·
تكلفة API بالدولار (اليوم/7/30) · متوسط سعر الرسالة · عدد الرسائل والإرساليات ·
التوزيع حسب اللغة والهدف · Top 10 مستخدم بالنقاط.

### 👥 إدارة المستخدمين
* بحث بالاسم/اليوزر/المعرّف (زر 🔍 ثم اكتب النص).
* تصفية حسب الهدف (تنحيف/ضخامة/لياقة/صحة…) وترقيم صفحات (25 لكل صفحة).
* الضغط على مستخدم يفتح **👤 الملف الكامل**: الاسم، المعرّف، اللغة، النقاط، الهدف،
  الوزن/الطول/العمر، السعرات والماكروز المستهدفة، حالة الكوتش والاشتراك، الستريك،
  ملخص آخر 7 أيام (سعرات/بروتين/التزام/تمارين)، آخر 5 حركات نقاط، الأوسمة، سجل الإحالة.
* من الملف: ➕/➖ نقاط (قيم جاهزة + مبلغ حر) · 💎 اشتراك (شهر/3 أشهر/إلغاء) · 🚫 حظر (مع سبب) · فك حظر.

### 📢 رسالة جماعية
1. اختر الجمهور: **الكل** / **النشطون** / **مشتركو الكوتش**.
2. أرسل النص (يدعم HTML) — يُقطع تلقائيًا إذا تجاوز 4096 حرفًا.
3. اختر: **إرسال فوري** أو **جدولة** (أدخل وقت UTC `YYYY-MM-DD HH:MM`).
4. التنفيذ يرسل بالتتابع مع `broadcast_delay_ms` بين الرسائل، يتخطى المحظورين
   (`TelegramForbiddenError`) ويسجّل النتيجة لكل مستهدف في `broadcast_targets`.
5. صفحة السجل تعرض لكل إرسال: الجمهور، العدد، نجح/فشل، الحالة.

### 🔗 الاشتراك الإجباري
تفعيل/تعطيل + تعيين رابط أو يوزر القناة (`@channel` أو `https://t.me/channel`).
**شرط:** أضف البوت مشرفًا في القناة، وإلا فشل التحقق وبقي المستخدم محجوبًا عن الخدمات.
كل مستخدم يرى زر «تحققت، أعد الفحص» عند الحاجز.

### 🤖 استهلاك API
اليوم/7/30 يومًا: إجمالي التكلفة بالدولار، عدد الاستدعاءات، معدل النجاح، متوسط زمن الاستجابة،
وتفصيل حسب المهمة والموديل. `/export` يضيف تسعير الموديلات.

### 🧩 توجيه الموديلات
جدول حي: المهمة ← الموديلات المرشحة بالترتيب ← هل هو تعديل أدمن أم افتراضي،
مع عرض السعر لكل موديل والسقوف الحالية (السقف العالمي، سقف نقاط المستخدم اليومي/الشهري).

### 🧾 سجل التدقيق
آخر إجراءات الإدارة (من فعل ماذا ومتى وعلى من) مع الحمولة — مفيد للمساءلة.

## 3. منح النقاط يدويًا

طريقتان متكافئتان (كلتاهما تكتب في `points_ledger` بسبب `admin_adjust`):

* من الملف: `➕ 100` ثم تأكيد، أو **مبلغ مخصص** ثم اكتب الرقم (يقبل سالبًا للخصم).
* من لوحة النقاط: نفس الأزرار بدون الدخول للملف.

الرصيد لا ينزل تحت الصفر؛ الخصم الأكبر من الرصيد يُقتطع عند الصفر مع تنبيه في الرد.

## 4. الاشتراكات

* **تفعيل اشتراك**: شهر (`SUBSCRIPTION_POINTS_MONTHLY` = 1500 نقطة) أو 3 أشهر.
* **التجديد التلقائي**: مهمة ساعوية تجدد الاشتراكات المنتهية وتمنح نقاط الفترة الجديدة،
  وتتوقف عن المستخدم الذي حظر البوت.
* **الإلغاء**: من زر «إلغاء الاشتراك» في الملف (يبقى الرصيد الحالي).

## 5. التشغيل اليومي — قائمة فحص

**قبل الإطلاق**
- [ ] `ADMIN_IDS` مضبوط (معرّفات رقمية، لا يوزرات).
- [ ] `NANOGPT_API_KEY` حقيقي و`GLOBAL_DAILY_USD_CAP` مناسب لميزانيتك.
- [ ] أسعار المهام في `.env` مطابقة لفاتورتك من NanoGPT.
- [ ] القناة موجودة والبوت مشرف فيها (إن فعّلت الاشتراك الإجباري).
- [ ] `WEBHOOK_SECRET` + `WEBHOOK_URL` إن استخدمت webhook (وإلا long polling).
- [ ] نسخة احتياطية: `scripts/backup_db.sh`.

**أسبوعيًا**
- [ ] راجع 📊 الإحصائيات (نمو المستخدمين، الإيراد بالنقاط، تكلفة API مقابل السقف).
- [ ] راجع 🧾 سجل التدقيق للتأكد أن كل تعديل نقاط مقصود.
- [ ] تأكد أن `ai_usage` success rate فوق 95%؛ إن نزل، راجع الموديلات/السقوف.

**عند الشكوى**
1. افتح 👤 الملف الكامل للمستخدم.
2. راجع آخر 7 أيام (هل الالتزام منخفض؟ هل تفوّت وجبات؟).
3. راجع آخر حركات النقاط (هل نفدت؟ هل هناك خصم مكرر؟).
4. عوّض بـ ➕ نقاط إن كان الخطأ من النظام، مع ذكر السبب (يُسجَّل في التدقيق).

## 6. حدود معروفة

* الحظر يمنع المستخدم من كل الخدمات لكنه لا يحذف بياناته (الحذف من ⚙️ الإعدادات لدى المستخدم).
* الإرسال الجماعية لا تدعم الوسائط بعد — نص فقط (HTML).
* `/export` يصدّر المستخدمين فقط، لا سجل النقاط الكامل (يُستخرج بـSQL أو من قاعدة البيانات).
* التعديلات على الموديلات عالمية (لكل المستخدمين) — لا يوجد توجيه per-user.
