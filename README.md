# 🏋️ الكوتش الذكي — AI Fitness & Nutrition Coach (Telegram)

بوت تيليجرام يعمل ككوتش شخصي بالذكاء الاصطناعي: استشارات مجانية، كوتش شخصي مدفوع بالنقاط
على مدار 24 ساعة، تحليل صور الأكل لحساب السعرات، برامج تدريب (منها ملاكمة من الصفر)،
تتبع يومي للوزن والقياسات، تقارير أسبوعية/شهرية، ولوحة أدمن كاملة.

> **A production-grade Telegram bot** built to the project specification: Arabic-first UX,
> token-metered points economy, per-task AI model routing with daily cost caps, privacy
> tooling (consent / export / delete), and an admin panel.

### الإضافات (كل الـ13 المطلوبة)
1. ⏰ **تذكيرات ذكية** — ماء/تمرين/ميزان/وجبات/صورة تقدم، بتوقيت المستخدم ومع ساعات هدوء ليلية.
2. 🔥 **الالتزام والأوسمة** — Streak + 13 وسام + نقاط مكافأة.
3. 🎁 **نظام الإحالة** — رابط وكود، نقاط للطرفين، مكافأة كل 5 أصدقاء.
4. 📏 **قياسات الجسم** — خصر/صدر/ذراع/فخذ/ورك/رقبة/ربلة/كتف/نسبة الدهون.
5. 📈 **رسم بياني للتقدم** — وزن + قياسات + سعرات (PNG بخطوط عربية).
6. 🚨 **تنبيهات السلامة** — كشف الإصابات والحالات الحرجة، استبعاد تمارين، بدائل آمنة، وتحويل طبي.
7. 🌍 **عربي/إنجليزي** — كتالوج ترجمة كامل (184 مفتاح) وتبديل فوري بـ `/lang`.
8. 🎙️ **الصوت → نص** — أرسل ملاحظة صوتية وتُفرَّغ ثم تُوجَّه للكوتش أو للاستشارة.
9. 💎 **اشتراك شهري/ربع سنوي** — تجديد تلقائي للنقاط كل 30 يوم (يُفعّله الأدمن).
10. 📄 **تصدير البيانات PDF** — رحلة المستخدم كاملة + تصدير خصوصية (GDPR).
11. 💵 **سقف تكلفة API** — حد يومي بالدولار على مستوى البوت + حدود نقاط يومية/شهرية لكل مستخدم.
12. 🔒 **سياسة خصوصية وموافقة** — موافقة إلزامية قبل الاستخدام، حذف صور، حذف حساب.
13. 🥊 **برنامج ملاكمة مرحلي** — من الصفر، مرحلة بعد مرحلة (لا نصائح عشوائية).

## 🧠 طبقة الذكاء الاصطناعي

مزوّد واحد: **NanoGPT** (متوافق مع OpenAI) — [nano-gpt.com/api](https://nano-gpt.com/api).
كل مهمة لها موديلها الخاص، مع سلسلة بدائل (fallback) تلقائية عند الفشل/الضغط:

| المهمة | الموديل الافتراضي | البديل |
|---|---|---|
| استشارة عامة | `z-ai/glm-5.3-flash` | `deepseek/deepseek-v4-flash` |
| كوتش شخصي | `deepseek/deepseek-v4-pro` | `z-ai/glm-5.3-flash` |
| تحليل صور الأكل | `google/gemini-3.5-flash-lite` | `google/gemini-3.5-flash` |
| برنامج تدريبي/ملاكمة | `deepseek/deepseek-v4-pro` | — |
| تقارير/تلخيص الذاكرة | `z-ai/glm-5.3-flash` | — |
| تفريغ الصوت | `Whisper-Large-V3` | `gpt-4o-mini-transcribe` |

* **مخرجات مُهيكلة**: مخططات JSON صارمة (`app/ai/schemas.py`) للأكل والبرامج والسلامة وإعادة حساب اليوم والاستشارة.
* **فيديوهات التمارين**: عبر NanoGPT Web Search (`includeDomains: youtube.com`) — **بدون مفتاح YouTube API**، مع كاش 30 يوم.
* **التكلفة**: تُقرأ من رد المزوّد إن وُجدت، وإلا تُحسب من جدول الأسعار؛ كل استدعاء يُسجَّل في `ai_usage`.
* **التوجيه حي**: تعديلات الأدمن تُحفظ في `app_settings` وتُطبَّق فورًا (كاش TTL).

### اقتصاد النقاط
`1 USD = 100 نقطة` · الترحيب `+20` · رسالة الكوتش تُسعَّر بالتوكنز بين `2` و`40` نقطة ·
إحالة `+25/+15` ومكافأة `+100` كل 5 · اشتراك شهري `+1500` · سقف يومي للمستخدم `800` نقطة وشهري `12000` ·
سقف عالمي `25$/يوم` (قابل للتعديل بـ `/cap`). كل حركة تُسجَّل في **سجل نقاط غير قابل للتعديل** (`points_ledger`).

## 🛠️ المتطلبات والتثبيت

* Python **3.11+**
* PostgreSQL **14+** (أو SQLite للتجربة/الاختبارات)
* مفتاح بوت من [@BotFather](https://t.me/BotFather) ومفتاح [NanoGPT](https://nano-gpt.com)
* اختياري: Redis (لعدة عمليات)، خط عربي مخصص للرسوم/تقارير PDF

```bash
git clone <repo> && cd Ch
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt

cp .env.example .env      # ثم عدّل BOT_TOKEN و NANOGPT_API_KEY و DATABASE_URL و ADMIN_IDS
./scripts/setup.sh        # اختياري: إنشاء المجلدات + تطبيق الهجرات
```

### قاعدة البيانات
```bash
alembic upgrade head                 # الإنتاج (PostgreSQL)
# أو اترك DB_AUTO_CREATE=true فيقوم البوت بإنشاء الجداول عند الإقلاع (تطوير فقط)
```

### التشغيل
```bash
python -m app.main                   # long polling (الافتراضي)
# أو مع webhook:
WEBHOOK_URL=https://bot.example.com python -m app.main
```
عند الإقلاع: تهيئة قاعدة البيانات ← إنشاء البوت ← تسجيل الأوامر ← تشغيل المجدول (تذكيرات/إرساليات/تجديد اشتراكات/تنظيف وسائط/تقارير) ← البدء بالاستقبال.
الإيقاف نظيف (SIGTERM/SIGINT): إيقاف المجدول ← إغلاق عميل الذكاء الاصطناعي ← إغلاق البوت ← إغلاق الاتصالات.

## 🔒 الخصوصية والأمان
* **موافقة إلزامية** على سياسة الخصوصية قبل أي استخدام (قابلة للتعطيل).
* **حذف الصور** (تقدم + أكل) و**حذف الحساب** بالكامل (GDPR-style wipe) من ⚙️ الإعدادات.
* **حذف تلقائي** للوسائط بعد `MEDIA_RETENTION_DAYS` يومًا.
* الصور تُصغَّر وتُخزَّن محليًا أو في S3/R2؛ لا تُستخدم لأي تدريب ولا تُشارك إلا مع مزوّد الذكاء الاصطناعي لمعالجتها.
* سجل تدقيق (`admin_actions`) لكل إجراء إداري، وأقنعة للمعرّفات في السجلات.
* **إخلاء مسؤولية**: البوت ليس بديلًا عن الطبيب؛ الحالات الحرجة (ألم صدر/قلب/حمل…) تُحوَّل لمختص وتُستبعد تمارينها تلقائيًا.

## ⚠️ ملاحظات تشغيلية
* التكلفة الحقيقية تعتمد على استخدام NanoGPT — اضبط `GLOBAL_DAILY_USD_CAP` و`*_POINTS_CAP` قبل الإطلاق.
* في الإنتاج استخدم PostgreSQL + Redis + `alembic upgrade head` و`DB_AUTO_CREATE=false`.
* للاشتراك الإجباري بالقناة يجب إضافة البوت **مشرفًا** في القناة حتى ينجح التحقق.
